One-line patch note for a bug in real life, entered in make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty. `main.py` (Python 3.13, standard library only) writes the entry to `/output/entry.txt`.

> v2.1.4: fixed a bug where a sneeze stalled at 99% and never fired, leaving the user cross-eyed in public.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
